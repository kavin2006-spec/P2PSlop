## How claims are tagged
- **[read]**: I fetched the source and read the figure or quote there.
- **[relayed]**: reported by a summary of the page, not read word for word. Check the original before quoting.
- **[estimate]**: my arithmetic or assumption. Say so if you publish it.
- **[unverified]**: from memory or a source I did not open. Check before use.
